\subsection{Ideal Behavioral Model}

As a reference for the designed power amplifier (PA), an ideal fully differential amplifier model has been implemented in Verilog-A. 
This behavioral model will be used as an ideal representation of the PA block during the initial system-level simulations and verification of 
the complete RF signal chain.

The amplifier has a differential input interface (\texttt{inp}, \texttt{inn}) and a differential output interface (\texttt{outp}, \texttt{outn}). 
The output differential voltage is proportional to the input differential voltage, according to the specified voltage gain:

\begin{equation}
    V_{\mathrm{out,diff}} =
    A_v \cdot V_{\mathrm{in,diff}}
\end{equation}

where:

\begin{equation}
    V_{\mathrm{in,diff}} = V(\texttt{inp}) - V(\texttt{inn})
\end{equation}

\begin{equation}
    A_v = 10^{G_{\mathrm{dB}}/20}
\end{equation}

The model also includes differential input resistance and independent series output resistances. 
The two output signals have equal amplitudes and opposite phases, assuming zero output common-mode voltage.

The Verilog-A implementation is presented below.

\begin{verbatim}
	`include "constants.vams"
	`include "disciplines.vams"
	
	module ideal_PA(inp, inn, outp, outn);
	
		input inp, inn;
		output outp, outn;
	
		electrical inp, inn, outp, outn;
		electrical nsrcp, nsrcn;
	
		parameter real gain_db = 20.0;
		parameter real Rin = 50.0;
		parameter real Rout = 50.0;
	
		real Av;
		real Vdiff;
	
		analog begin
	
			// Differential voltage gain
			Av = pow(10.0, gain_db/20.0);
	
			// Differential input voltage
			Vdiff = V(inp, inn);
	
			// Differential input resistance
			I(inp, inn) <+ V(inp, inn)/Rin;
	
			// Controlled differential voltage sources
			V(nsrcp) <+ (Av/2.0) * Vdiff;
			V(nsrcn) <+ -(Av/2.0) * Vdiff;
	
			// Output resistance
			I(outp, nsrcp) <+ V(outp, nsrcp)/Rout;
			I(outn, nsrcn) <+ V(outn, nsrcn)/Rout;
	
		end
	
	endmodule
	\end{verbatim}


	This ideal behavioral model will serve as a reference for the subsequent design and simulation stages. 
	It allows the PA block to be integrated into the complete system before the transistor-level implementation is finalized. 
	The model will also facilitate comparison between ideal and transistor-level simulation results.
